Mes commandes Azure

Toutes les commandes croisées pendant le parcours, avec leur équivalent CLI ↔ PowerShell. Tape un mot (ex. « groupe », « dns », « rôle ») ou filtre par outil.

Rappels : Azure CLI (az …) = tout en minuscules, sensible à la casse. PowerShell = Verbe-Nom (Get, New, Remove, Set…), insensible à la casse, et le tube | passe des objets, pas du texte. Dans Cloud Shell, tu changes avec pwsh ou bash.
